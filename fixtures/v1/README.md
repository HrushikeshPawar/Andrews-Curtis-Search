# Kernel fixtures v1

Shared JSON for the Python and Rust kernels. Expected values were generated
from the official SAIR verifier (`ac-r2-v1`).

- `words.json` — free reduction and inverse
- `moves.json` — each named move on several presentations, plus inverse round-trip
- `presentations.json` — two-relator states and the exact AC target
- `certificates.json` — named-move paths, contest ids, and replay
